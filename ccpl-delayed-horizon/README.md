# Delayed Horizon

Delayed Horizon is a browser-based 3D showcase for CCPL. It presents a small
autonomous freight world where route decisions can create hazards whose costs
appear later. The browser is a visual replay and comparison surface; the
rollouts are generated by the Python CCPL package.

## Run a real CCPL rollout

From the repository root:

```powershell
py -3.11 ccpl-delayed-horizon\generate.py `
  --checkpoint ccpl-saferoute\results\local_sweep_1000\ccpl_seed42.pkl `
  --seeds 42,46,146,222,555,777 `
  --delay 10 `
  --output ccpl-delayed-horizon\data\rollouts.json

cd ccpl-delayed-horizon
py -3.11 -m http.server 8765
```

Open `http://127.0.0.1:8765`.

The generator loads the checkpoint with `CCPLAgent.load`, evaluates it without
training, and records the route trace, delayed consequence, hazards, reward,
and completion for each seed. The browser does not claim to train an agent.

## Controls

- Drag to orbit the world.
- Scroll to zoom.
- Use the rollout selector to compare seeds.
- Pause or replay the route.
- Toggle the consequence rings and route trace.

## Research scope

This is a controlled visualization of the SafeRoute environment. It is useful
for inspecting delayed feedback and action selection, but it is not evidence of
real-world causal discovery, safe deployment, or universal CCPL superiority.
